# Handies for Cash!, rebuilt for the browser

(Draft for the itch.io devlog. Type: Major Update. Posted by hand or, if the user asks, through Chrome with the AI-agent line at the end.)

Handies for Cash! has been rebuilt in Odin and WebAssembly, like a lot of my older metaphors this autumn. Same abandoned house, same dark alley, same pay toilet, same five cash a time.

What changed:

- It saves as you play, in your browser, and picks up where you left off. The old version never saved.
- Sleeping on the stained mattress now costs food. It used to feed you, which was a bug.
- The messages say what actually changed ("gains 5 stomach" when yer stomach only had room for 5).
- "has given 1 handy" instead of "1 handies".
- If you do not type a name, you get the default name the original always meant to give you.
- It has a layout for phones held upright, and you can tap the choices.

The latest version is always at https://playdeezgames.github.io/handies-for-cash/ too.

The port was written by Claude Code, an AI agent, at my direction. The metaphor itself is the August 2026 original.
